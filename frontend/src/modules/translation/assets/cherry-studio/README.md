# Cherry Studio 翻译资源

`upload-*.svg` 来源于 Cherry Studio 社区版的 `src/renderer/assets/images/translate/`。`deepseek.svg` 来源于 `packages/ui/icons/models/light/`。Cherry Studio 项目的授权见 [AGPL-3.0](../../../../../public/cherry-studio/LICENSE)。

`TwemojiCountryFlags.woff2` 是 Cherry Studio 使用的 [country-flag-emoji-polyfill 字体](https://github.com/beyondkmp/country-flag-emoji-polyfill/blob/master/font/TwemojiCountryFlags.woff2)，位置为 `src/renderer/assets/fonts/country-flag-fonts/`。
