# QMS 首页与新对话采用工作台布局

状态：implemented
类型：feature
Owner：frontend/src/pages/HomeView.vue

## 问题

公开首页的流线和居中排版、新对话的随机问候与原项目视觉相近。QMS 需要可识别的品牌入口和明确的对话起点。

## 决策

### 实现方案

HomeView 使用深青品牌区和输入面板的双栏排版。品牌区显示配置口号，输入面板沿用登录导航和草稿交接。此决定更新[首页单屏输入入口与知识流线](2026-10-16-home-entry-screen.md)中的背景、排版和按钮样式。

SessionWorkspace 使用现有的新会话条件显示简短标题、机器人头像和居中输入框。工具栏中的「项目」位于智能体与审批控件之间。对话建立后，输入框由历史会话布局置于底部。

## 替代方案

在原布局上调整颜色会保留首页流线和新对话随机问候的视觉特征。新对话的大面积横幅会占用输入区上方空间，简短标题可以更快引导到输入框。

## 后果

窄视口使用弹性列宽，较长的配置口号可自然换行。布局由现有 Vue 视图和 CSS 提供，首页背景无需 Canvas 绘制。

## 验证

- `frontend/test/browser/homeEntry.js` 核对双栏、浅深色、窄屏与登录前后的草稿交接。
- `frontend/test/unit/sessionWorkspaceVisibility.test.js` 核对新对话条件和已有会话标题隐藏。浏览器在 1440px 和 768px 视口核对标题、项目选择及输入框的实际排列。
