# 个人空间预览跟随页面激活状态

状态：implemented
类型：bug-fix
Owner：frontend/src/pages/WorkspaceView.vue

## 问题

个人空间由应用布局的 KeepAlive 缓存。离开路由后，ResizeObserver 可以报告隐藏容器的零宽度；仅按宽度切换预览形式会把侧栏预览转换成仍挂在全局 DOM 的弹窗，遮挡其他页面。窄屏原有弹窗也需要随页面失活隐藏。

## 决策

### 实现方案

WorkspaceView 拥有页面激活状态和文件预览。弹窗打开条件包含页面激活状态，失活时停止预览拖拽，并暂停宽度驱动的预览形式切换；重新激活时先读取当前容器宽度，再恢复现有目录及文件刷新流程。文件选择和预览数据继续保留在缓存页面内，宽屏回到侧栏，窄屏回到弹窗。

该修复直接实现明确的页面生命周期边界，没有需要先裁决的公开接口、持久数据或权限变化，因此记录当前决定，不另设提案阶段。

## 替代方案

- 离开时清空全部预览：会丢失返回个人空间时的文件选择，削弱现有缓存体验。
- 取消个人空间的 KeepAlive：同时重置目录和页面状态，影响范围超过文件预览。
- 仅忽略零宽度：无法隐藏用户在窄屏已经打开的弹窗。

## 后果

预览展示限制在激活的个人空间页面；页面激活期间的正常宽窄屏切换保持有效。隐藏期间的宽度变化在重新激活时重新测量，不作为打开弹窗的用户动作。接口和文件保存语义保持不变。

## 验证

- `docker compose exec frontend node --test test/unit/workspacePreviewLifecycle.test.js`：覆盖宽屏失活后零宽度、窄屏弹窗失活、返回恢复及激活期间缩窄。
- 移除弹窗激活条件和宽度 watcher 的失活检查后，上述测试因离开页面仍出现弹窗失败；恢复实现后通过。
- 真实浏览器验证个人空间打开文件后切换到智能体页面，核对目标路由没有文件预览弹窗，并返回个人空间核对预览恢复。
