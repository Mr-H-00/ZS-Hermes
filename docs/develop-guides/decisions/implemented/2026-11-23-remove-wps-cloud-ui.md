# 企业智能体移除 WPS 云盘网页入口

状态：implemented
类型：simplification
Owner：frontend/src/pages/WorkspaceView.vue

## 问题

企业智能体的网盘只需要工作区和个人成果。WPS 云盘与云盘配置属于同一项网页集成。

## 决策

### 实现方案

网盘装配工作区和成果浏览器。旧的云盘页签链接进入工作区。设置弹窗只保留其他设置，浏览器路由移除 WPS 授权回调。WPS API 和持久化由 identity 模块维护。

## 替代方案

只隐藏菜单会让旧链接继续进入 WPS 页面。删除服务端集成会影响 API 调用方及已有连接记录。

## 后果

用户可继续浏览工作区和个人成果。已经发起的 WPS 网页授权无法通过原网页回调完成。

## 验证

在运行中的前端打开网盘、原云盘地址和设置，检查 DOM，并检查打开页面时是否请求 WPS API。

旧能力不存在：网页中无云盘页签、云盘配置和 WPS 回调组件。

重新引入条件：产品启用 WPS 网页接入时，按授权回调和权限契约恢复。
