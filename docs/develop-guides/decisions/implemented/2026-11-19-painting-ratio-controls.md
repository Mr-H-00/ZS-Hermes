# 绘画比例与生成数量控件

状态：implemented
类型：feature
Owner：frontend/src/modules/paintings/ui/PaintingWorkspace.vue

生成数量的多图协议和结果处理见[绘画生成数量与多图结果](./2026-11-19-painting-batch-count.md)。

## 问题

绘画参数目前只显示供应商尺寸字符串。用户需要 Cherry 参考界面的比例卡片，并保留生成数量字段，生成数量位于比例选择上方。

## 决策

### 实现方案

参数弹层先显示可编辑的生成数量，再显示四列两行的比例卡片，顺序为自动、9:16、2:3、3:4、1:1、4:3、3:2、16:9。模型目录由 Seedream 的分辨率档位和受支持比例返回映射，固定尺寸模型只映射其确有的比例。页面对缺少映射的卡片禁用并保留完整位置。自动保留 Seedream 的 2K 档。选定比例时提交目录中的对应尺寸。生成数量由所选模型的能力校验，当前模型上限均为一张。

## 替代方案

在前端按宽高字符串自行猜测比例会把供应商尺寸规则复制到 UI。只显示原始尺寸不能满足截图中的比例选择。开放多个生成数量则须由供应商协议、结果解码、接口响应及画板历史共同支持，当前模型未承诺此能力。

## 后果

选中 Seedream 的「自动」会提交 2K 档，供应商根据提示词推断画面比例。比例图标标签使用标准比例，实际提交像素尺寸来自模型能力映射。历史记录保存和恢复提交的尺寸原值。
