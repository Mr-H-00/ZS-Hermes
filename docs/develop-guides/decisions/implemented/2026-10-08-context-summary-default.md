# 默认上下文压缩阈值为 256K

状态：implemented
类型：feature
Owner：backend/yuxi/modules/agents/runtime/context.py

## 问题

长任务需要在自动压缩前保留更多原始上下文。缺省阈值改变模型可见输入长度，必须明确默认值、已有配置和模型窗口之间的关系。

## 决策

未显式配置的 Context 使用 256K 压缩阈值，已有显式配置保持原值。决定仅调整单一缺省值，无需新增运行时策略或配置迁移，因此直接记录为 implemented。

### 实现方案

Context 拥有默认值与表单 schema；摘要 middleware 将配置乘以 1024，使用 262144 token 作为缺省触发阈值。手动压缩建议仍使用配置阈值的 85%。当前机制与管理员配置说明由[上下文压缩](../../../mechanisms/context-compression.md)拥有。

## 替代方案

保留 100K 会更早压缩长任务。按模型窗口自动取较小值需要可信模型窗口来源及新的运行时策略，超出本次默认值修改范围。

## 后果

未保存阈值的 Agent 更晚自动压缩，模型请求可能更长。256K 默认值需要模型具备足够的输入窗口并预留输出和工具开销；小窗口模型由管理员显式降低阈值。默认值不承诺所有模型均可容纳 262144 token，真实 provider 长上下文行为尚未验证。

## 验证

Context 测试核对缺省值与配置 schema 均为 256，并验证显式阈值覆盖；摘要 middleware 的现有单测核对 K 到 token 的换算和压缩触发行为。实际命令和结果随交付报告记录，真实 provider 长输入为 Not run。
