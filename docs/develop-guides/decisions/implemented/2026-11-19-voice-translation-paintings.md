# Web 语音、翻译与绘画

状态：implemented
类型：feature
Owner：frontend/src/app/layouts/AppLayout.vue

翻译和绘画的页面及文件处理由 [Cherry 工作区决策](./2026-11-19-cherry-translation-paintings.md) 接续。此记录保留语音和 Web 一级入口的决定。

## 问题

登录用户需要在聊天中听写和朗读，并能从一级导航独立翻译文本或生成图片。三个入口需要沿用 Yuxi 的权限、模型配置和页面布局。

## 决策

### 实现方案

- 语音模块通过浏览器 Web Speech API 提供听写和朗读，按登录用户保存本机偏好。听写由用户触发，开始前说明浏览器供应商处理音频的可能性。转写内容进入当前会话草稿。只有当前会话的新权威结果可以触发自动朗读，且音色必须在设备本地。
- 翻译通过认证 Web API 调用启用的聊天模型。领域服务拥有语言、文本、输出和超时约束，并在调用供应商前释放配置读取事务。浏览器单次提交并显示可复制的译文。
- 绘画通过认证 Web API 调用显式配置的生图模型。供应商管理和模型目录拥有模型类别、授权配置与凭据。模型适配器执行 OpenAI GPT Image 兼容的单图请求并验证图片字节。绘画服务编排配置读取和生成，浏览器负责预览与下载。结果限于页面生命周期。

## 替代方案

- Electron 语音适配器依赖本机进程。浏览器方案沿用 Web 部署，受支持音色和听写实现以实际设备为准。
- 将翻译或绘画包装成 Agent Run 会引入隐式会话与执行数据。同步 Web 请求符合单步工具的交互，有限超时限制其服务端生命周期。
- 支持供应商临时 URL 和持久历史会增加外部下载授权和数据所有权。首版选择直接返回图片字节。独立页面的下载由用户操作，Agent 正式 Run 产物继续由 Workspace 发布。

## 后果

依赖浏览器权限、可用语音引擎及已配置供应商。语音自动朗读以服务端持久的完成时点判断回复是否在当前会话视图打开后生成，浏览器与服务器时钟偏差可能跳过朗读。翻译文本与绘画提示词发送给配置的服务端供应商。

## 验证

- 会话语音和事件流测试覆盖账号和当前草稿绑定、听写权限拒绝、旧终态、回读归属和本地自动朗读。
- 翻译与绘画的 HTTP 测试使用 PostgreSQL、真实登录和确定性的模型上游，验证请求体、禁用模型拒绝、译文或可解码图片。浏览器核对导航、刷新、译文和下载。
