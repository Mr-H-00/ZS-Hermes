# 绘画模型尺寸与输入快捷面板

状态：implemented
类型：bug-fix
Owner：frontend/src/modules/paintings/ui/PaintingWorkspace.vue

## 问题

模型选择器打开时刷新模型目录，绘画参数只读取页面挂载时的快照。新模型可被选中，尺寸和参考图能力却仍为空。当前方舟 Seedream 模型也需要其实际支持的尺寸和请求字段。绘画底栏的加号缺少 Cherry 的提示词入口。

## 决策

### 实现方案

模型选择器将本次选中的目录记录随现有 spec 事件一并提供给绘画。绘画使用同一记录显示尺寸和参考图限制，晚到的初始目录保留用户的新选择。底栏加号打开输入快捷面板，复用参考图上传和提示词库。方舟 Seedream 的能力和调用协议由模型适配器提供，绘画服务按同一规则校验请求。原绘画工作区的决策见 [Cherry 工作区迁移](./2026-11-19-cherry-translation-paintings.md)。

## 替代方案

在绘画前端维护尺寸常量会与执行端的尺寸约束分别演进。接入新的共享工具运行时会扩大两项操作的改动面，当前组件已有对应操作。

## 后果

Seedream 的 K 档位由供应商结合提示词决定实际宽高。绘画表单只显示已验证协议的档位，参考图上限为三张。缺少已知能力的方舟模型不提交生成请求。

## 验证

- Edge 在真实页面使用受控 HTTP 数据，复现并验证挂载后新增模型、768px 尺寸摘要、提示词库、参考图能力限制及生成请求的尺寸和文件字节。
- Edge 使用真实 Yuxi HTTP 和已配置的四个 Seedream 型号，验证目录提供的分辨率档位和参考图入口。
- 后端 pytest 使用真实 Yuxi HTTP、PostgreSQL、Redis 和受控上游校验 Seedream 档位、认证、参考图的请求格式和响应图片。真实付费生图未执行，供应商 API 协议以[方舟图片生成文档](https://www.volcengine.com/docs/82379/1541523)核对。
