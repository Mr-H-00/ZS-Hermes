# 模型供应商的类型标识

状态：implemented
类型：bug-fix
Owner：backend/yuxi/modules/models/providers/service.py

## 问题

模型管理需要使用稳定的技术类型名，同时为远端候选提供中文筛选。已有图片模型和客户端使用旧类型值。

## 决策

### 实现方案

模型配置、目录和管理接口统一使用 `chat`、`embedding`、`rerank`、`image`、`video`、`audio`、`seed3D`。管理页的候选筛选使用中文。模型域在配置写入和读取边界转为统一类型名，读取旧图片配置、Redis 缓存和列表查询时接收 `image_generation`，旧值 `3d` 映射为 `seed3D`。

## 替代方案

只改界面文案无法让配置和远端目录使用相同类型。一次性重写数据还需要协调缓存和旧调用方。

## 后果

配置中使用技术名称。视频、语音与 3D 支持管理和目录查询，连接测试返回暂不支持。绘画继续按其图片接口执行。

## 验证

真实 HTTP 和独立 PostgreSQL Schema 验证新类型保存、旧图片配置重读、目录分组、缓存更新及绘画入口。单测覆盖旧缓存和状态检查。管理页单测和浏览器验证技术名称与中文筛选顺序。
