## 问题

Yuxi 的一级导航已经提供翻译和绘画。用户需要 Cherry Studio 社区版两项工作区的布局、控件和工作流，包括截图中的翻译设置和绘画模板。

## 决策

### 实现方案

翻译和绘画在 Yuxi 一级导航下独立路由。Vue 页面以 Cherry 社区版的翻译工具栏、双栏、设置和历史，以及绘画缩略条、模板轮播、画板和底部编辑器为参照。随 Cherry 社区版发布的模板和界面资源保留来源和 AGPL-3.0 许可证。浏览器负责上传、剪贴板、下载和听写，历史按登录账号保存在浏览器。

翻译 API 负责聊天模型调用、语言检测和正文提取。PDF 版式接口使用 Linux API 环境内的 BabelDOC Stream，经单次回环模型接口调用已授权的翻译模型。可选执行器不可用时，页面提供正文翻译。保存译文使用 Yuxi 网盘上传接口。

绘画读取模型目录的尺寸、参考图数量和可用参数。绘画 API 校验模型、表单和图片，按现有 GPT Image 兼容协议或硅基流动 Qwen Image 协议获得一张结果。Qwen 签名图像只从验证过的硅基流动对象服务下载，下载不携带供应商凭据。浏览器接收校验后的字节，自行预览、保存历史和下载。Web 登录、语音和 Agent 产物边界见 [首版记录](./2026-11-19-voice-translation-paintings.md)。

## 替代方案

直接运行 Cherry Electron renderer 需要原应用的 preload、进程间协议及桌面文件系统。Vue 移植将桌面依赖替换为已有浏览器和认证 HTTP 边界，适配点以实际功能验证。

## 后果

文件解析受已配置的 OCR 能力约束，PDF 保版式受独立可选运行环境约束。绘画模型由管理员启用，当前提供单次单图和所列模型实际支持的参数。浏览器历史随当前设备保存，关闭标签页会结束当前页面的生成状态。

## 验证

- Edge 中核对翻译双栏、右侧设置和绘画模板页面，对照用户截图查看实际渲染。
- 使用有认证的 Yuxi HTTP 和确定性上游验证上传、文本翻译、生成、图片解码和下载。定向绘画 pytest 的 13 项协议测试和 1 项真实 HTTP 集成通过。已用真实硅基流动 API 验证 Qwen 文生图和参考图编辑能返回可解码 PNG。
- PDF 正文提取已验证文本层及办公文档。PDF 保版式实际部署需安装和预置引擎资源。部署说明见 [模型配置](../../../intro/model-config.md#为-pdf-翻译配置版式引擎)。
