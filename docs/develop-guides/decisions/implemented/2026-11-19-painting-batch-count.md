# 绘画生成数量与多图结果

状态：implemented
类型：feature
Owner：backend/yuxi/modules/models/images.py

## 问题

生成数量虽已显示在绘画参数内，服务端和所有图片解码器仍把结果限制为单张，因此增加数量会失败。

## 决策

### 实现方案

由模型能力返回生成数量上限，绘画页面据此显示带上下箭头的数字输入。只对供应商协议已确认支持批量的 Seedream 5.0 Lite、4.5 和 4.0 提供最多 15 张的多图请求，提交组图模式和数量。服务端校验数量，按单图和总响应预算解码图片列表，再由现有响应、画板和账号隔离的浏览器历史传递图片列表。固定单图模型继续限定数量为一张。

## 替代方案

只做数字控件会把不受支持的值提交到上游，并可能造成额度支出但页面无结果。

## 后果

单图模型的输入仍允许显示 1，但上下箭头在 1–1 范围内不会产生可用的第二个值。Seedream 组图结果在画板下方可切换，下载按钮针对当前选中图片，历史记录保留整组图片。

## 验证

- Edge 受控页面验证数量控件的上下箭头、1–15 范围、两张结果请求和结果列表。
- 后端 28 项生图单测及 1 项绘画 HTTP integration 验证组图 wire、严格结果数量、单图兼容和超限拒绝。
- 每图 12 MiB、组图总计 48 MiB，响应读取上限 64 MiB。
