# WPS 云盘

本页面向配置 WPS 应用与部署回调的管理员。连接链路由应用配置、用户 OAuth、持久凭据和云文档读取组成。

## 配置与授权

在设置的云盘页登记 WPS 应用 ID、应用密钥和公网 HTTPS 回调。回调路径固定为 `/auth/wps/callback`，不接受 IP、localhost、查询参数、片段或内嵌凭据。WPS 控制台登记的回调必须与页面配置一致。正式接入使用部署方拥有的域名与 HTTPS 入口。

应用密钥与个人 access/refresh token 以领域隔离密钥加密保存。持久 `API_KEY_DERIVATION_SECRET` 变化会影响既有凭据解密；不要把它放入前端或 Agent 沙盒。每位用户从工作区的 WPS 页单独授权，回调只消费当前用户的有效一次性 state。应用配置发生变化后，旧连接需重新授权。

WPS 文件列表、搜索和文档链接来自当前用户连接。连接失败或刷新失败应在页面显示错误；已有设置和本地工作区继续保留。其他空间的占位页面不表示已接入第三方网盘。

## 开发隧道

开发 Compose 仅向 API 只读挂载 `CLOUDFLARED_CONFIG_DIR`，默认是 `docker/cloudflared`。`config.example.yml` 给出新 `frontend` 服务的转发目标。实际 config、Tunnel credentials JSON 和域名 DNS 权限由部署方提供，凭据不能提交。

当前开发联调流程使用既定命名隧道与固定回调域名。配置不符合该流程时显式拒绝，不自动创建 DNS 或任意公网入口。API 按用户请求启动隧道，通过前端页面与当前 API 随机回声确认入口，进程退出时回收自己启动的隧道。生产 Compose 不发布开发隧道。

## 验收边界

协议回放可验证 state 重放拒绝、配置权限、用户隔离、加密保存和 token 刷新；隧道测试可验证进程生命周期与探针。真实接入仍需 WPS 应用权限、控制台回调、DNS、Cloudflare 凭据及浏览器授权结果。只有页面实际可读取本人文档，才完成外部接入验收。
